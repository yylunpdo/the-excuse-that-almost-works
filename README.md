One line a gamer texts the boss to skip work on GTA 6 launch week —
an excuse that sounds almost believable, then collapses on its own logic.

## The entry

> Sorry boss, my work laptop froze mid-update and IT says it's stuck downloading GTA 6 until lunchtime.

It opens like a real, boring IT problem — a work laptop frozen mid-update,
IT involved — and then the download it is stuck on turns out to be GTA 6
itself. The manager almost believes the first half; the second half is the
confession.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` uses only the Python standard library. It writes exactly one line
(17 words, 101 characters) to `/output/entry.txt`, deterministically — the
same bytes on every run.
